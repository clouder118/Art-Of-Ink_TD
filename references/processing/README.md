# Processing 原作参考

此目录保存原作主程序和密度注入着色器的原样副本，用于理解流体交互及对照效果，不在这里修改原作逻辑。

原作仓库：[clouder118/Art-Of-Ink](https://github.com/clouder118/Art-Of-Ink)。复制基线提交：`5584553f3ab070b95508e214a9277fa031476d0f`。

- `project_5.pde`：窗口初始化、图像注入、鼠标速度交互、渲染和音乐播放。
- `data/addDensity.frag`：将原图混入流体密度场；保留原有 PixelFlow 版权与许可说明。
- 图片与音乐位于新仓库的 `TD/assets/`，没有在本参考目录重复保存。

这些文件用于源码参考，并非可直接运行的独立草图包。如需运行对照，请使用原作仓库及其 README 中的完整资源与依赖说明。

**原作必须使用 Processing 3.5.4，最新版会因兼容性问题导致显示异常。**
