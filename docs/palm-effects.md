# 摊手循环水墨效果

日期：2026-10-22。此规格扩展首版的单食指交互边界；Processing、Liquid 参考工程不修改。实现与交付继续位于 Art-Of-Ink_TD。

## 行为

- 食指沿用 Gain 24、20 FPS 识别、镜像映射和连续位移补帧。
- 五指伸直并自然张开，连续有效至少 0.20 秒且包含至少三个新识别结果，启动一次摊手效果。静止摊手也有效。
- 全局顺序：斜向波浪 → 向外螺旋 → 扩散水波 → 斜向波浪。换手共用顺序；连续摊手不切换种类。另一只手不能抢占当前控制手。
- 第一次非摊手即停止新增作用，非摊手持续 0.25 秒后重新允许触发；短暂误判后恢复同一效果，数据过期 0.30 秒结束本轮。握拳不重置、不冻结、不新增效果，残余流动自然消散。
- 波浪为起伏波前，从画面左下向右上推进，4 秒一轮；螺旋以画面中心顺时针旋转并向外展开；水波从中心向四周径向扩散，3 秒一轮，不旋转。中心不跟随手掌。
- 效果明显但保留山水结构，直接输运原山水墨色；不叠加图形。原图恢复速度不变。
- 重新打开工程或恢复原图后从波浪开始；恢复原图时若仍摊手，必须先收手才能触发。只重启摄像头保留顺序。

## 实现接口

复用本地 MediaPipe 21 个手部关键点，无新增模型和在线依赖。`Interaction` 保留原食指输出字段并增加 `gesture`（`none/index/palm`），统一选择和锁定控制手。摊手输出不向食指速度场施加位移，手势切换清空补帧队列并重新建立食指基准。

独立的纯 Python `PalmEffects` 管理循环、确认、防抖和渐变，输出 `effect`、`effect_id`、`next_effect`、`effect_time`、`effect_strength`、`palm_active`。`effect` 在退出后的残余阶段仍表示上一种效果；是否仍在摊手以 `palm_active` 为准。

图像平流着色器的 `uPalm` 为模式、时间、包络、强度倍率。效果速度按图像高度计算、校正横纵比，在压力投影之后与原速度合成，不写回原速度反馈，避免径向效果被压力抵消及速度不断累加。约 0.25 秒达到进入强度的 95%，退出按 0.45 秒时间常数衰减。图像仍使用 32 位浮点反馈及原 Restore 0.54。

维护参数新增 `Palmstrength`（默认 1，范围 0–3）；摄像头预览默认打开、音乐循环和调试开关保持原行为。调试模式与本地状态文件显示当前手势、当前/下一效果；纯净山水不增加调试文字。

## 验证

35 项 Python 测试和 8 项 Node 测试通过。新增测试覆盖旋转/镜像摊手、拇指收起/部分伸指/握拳/异常点、控制手切换、六次循环、保持不连跳、重复帧、短暂丢失、失联、重启摄像头及恢复原图；重启摄像头也不能绕过恢复原图后的收手要求。

`TD/tools/validate_palm_effects.py` 在原生 TD 中临时自动驱动三种效果，完成或捕获测试回调异常后恢复真实控制器；只保存山水画面及汇总指标。实际 GLSL 速度场通过方向检查，三种效果各作用 5 秒、恢复 8 秒，残余平均 RGB 差异分别约为作用结束时的 2.70%、2.36%、2.38%，均为有限值，无节点错误。详见 [原生验证](validation/palm-effects/native-validation.json)。

用户真实手势完成六次“摊手 6–8 秒、收手至少 1 秒”并回归食指，确认：“顺序正确，三种效果明显，食指正常”。

正式工程重开后的五分钟只读观察共 300.36 秒、297 次每秒状态采样：滚动 600 帧 FPS 均值 **59.993**，最低 **59.789**，最大滚动 P95 帧间隔 **17.445 ms**；47 次采样有有效摊手，覆盖波浪、螺旋、水波，另有 4 次食指激活样本，所有样本摄像头 ready、无节点错误或读取失败。用户确认“观察完成，流畅且切换、恢复正常”。[完整采样](validation/palm-effects/performance.json)

这些值来自相互重叠的滚动窗口，不能当作独立逐帧计数的全程平均帧率，未测量光学端到端延迟，未验证小时级连续运行。测试限定本机 TD 2025.32820、RTX 4060 Laptop GPU、内置摄像头、预览开启及音乐同时运行。

用户最后完全关闭 TD、断网并重新打开正式工程，确认预览默认出现、音乐和食指正常，且“全部正常，第一次摊手是波浪”。[离线验收](validation/palm-effects/offline-acceptance.json)；交付审查确认无开发桥、测试节点或运行状态存储，默认 20 FPS、强度倍率 1、预览打开，详见 [工程哈希与审查](validation/palm-effects/delivery-audit.json)。自动验证与真实手势、离线验收分别记录。
