# 领域文档与用语

本仓库采用单一领域上下文。

- 开始相关开发前阅读 [中文 PRD](../td-prd.md)、[开发任务拆分](../td-issues.md) 和目标 GitHub 议题。
- 若存在根目录 CONTEXT.md，先阅读领域词汇；若存在 CONTEXT-MAP.md，按其映射阅读相关上下文。
- 阅读与当前任务相关的 docs/adr/ 决策。文档不存在时继续工作，无需为占位创建空文件。
- 任务拆分不能反向改变已确认的产品需求；遇到已有 ADR 冲突时显式说明。
- 统一使用：山水原图、速度扰动、有效手势、控制手、单手独占、镜像映射、原图恢复、正式展示、调试模式、离线冷启动。
- Liquid 只是只读效果参考，不能视为必须复用的架构或已经确定的运行依赖。
- 流畅度优先，以稳定 60 FPS 为目标；兼容性、离线启动、帧率及真实手势效果必须通过本机验证，不得把规划或模拟测试报告为已实现。
- 新工程在 TD 区域开发，原 Processing 参考源码和用户原始 Liquid 工程保持不变。
