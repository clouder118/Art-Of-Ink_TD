# Art of Ink · 手势交互水墨山水

一幅可以用手势推动的数字水墨山水。作品通过摄像头捕捉手部动作，让山水中的墨色局部流动、旋转与扩散，停止交互后逐渐恢复原画，并伴随《山居吟》循环播放。

本仓库提供可在本机 TouchDesigner 中打开的完整作品工程，包含山水、音乐、交互模块和本地手部识别资源。下载整个仓库、安装指定版本的 TouchDesigner 后，即可部署体验，无需编译或另外安装识别服务。

作品位于 **`Art-Of-Ink_TD_Artwork` 分支**，请通过以下入口获取对应内容：

**[下载完整作品 ZIP](https://github.com/clouder118/Art-Of-Ink_TD/archive/refs/heads/Art-Of-Ink_TD_Artwork.zip)** · **[浏览作品分支](https://github.com/clouder118/Art-Of-Ink_TD/tree/Art-Of-Ink_TD_Artwork)**

## 体验方式

面向摄像头，让整只手清晰可见。单次由一只手控制，左右手均可；当前控制手移开后，另一只手可以接管。食指操作采用镜像映射。

| 手势 | 画面反应 |
| --- | --- |
| 仅食指伸直，其余三指收拢，拇指自然放松 | 移动食指，推动对应位置的水墨；静止时不持续新增推动 |
| 五指自然伸直并张开 | 保持约 0.2 秒，启动当前摊手效果；无需移动手掌 |
| 握拳、收指或移开手 | 停止新增作用，已有流动自然消散、山水逐渐恢复 |

每次摊手按以下顺序循环：

1. **斜向波浪**：波前从左下角向右上角推进，约每 4 秒一轮。
2. **向外螺旋**：围绕画面中央顺时针旋转，并向外舒展。
3. **扩散水波**：从画面中心向四周扩散，约每 3 秒一轮。

持续摊手保持同一种效果；收手至少约 0.25 秒后再次摊手，进入下一种。换手共用循环顺序。重新打开作品或执行恢复原图后，从波浪开始；若恢复原图时仍摊着手，需要先收手再触发。

## 环境与安装

- **推荐运行环境：Windows，TouchDesigner 2025.32820。** 此版本已实际验证；其他系统及版本需在展示前自行确认。
- 从 [Derivative 官方历史版本下载页](https://derivative.ca/download/archive) 获取对应版本，安装并完成 TouchDesigner 的首次账户与许可设置。按自己的使用场景选择适用许可，详见 [官方说明](https://derivative.ca/download)。
- 需要可用的笔记本内置摄像头或 USB 摄像头，以及扬声器或耳机。建议使用独立显卡，并保持显卡驱动可用。
- 作品输出为 **1280 × 647**，全屏等比适配。识别目标默认 **20 FPS**，画面渲染以约 **60 FPS** 为目标，实际表现取决于电脑配置。
- 无需额外安装 Python、Node.js 或手势识别依赖，无需另开浏览器或运行命令。

## 启动与展示

1. 完整解压或克隆本仓库，保持工程与资源的目录结构；建议放在本机可读写的普通目录。
2. 安装并启动 TouchDesigner 后，双击文件夹根目录的 **`ArtOfInk_TD.toe`**；也可在 TouchDesigner 中通过 File → Open 打开。
3. 工程会进入全屏山水展示，自动加载本地手部识别资源、开启摄像头预览并播放音乐。首次加载请稍等片刻。
4. 使用前确认系统允许 TouchDesigner 使用摄像头。避免会议软件、直播软件等同时占用摄像头，尽量使用均匀室内光线。
5. 面向摄像头伸出食指或摊开五指，即可交互。每次打开工程，摊手顺序从波浪开始。

右上角摄像头预览默认打开，点击 **×** 只隐藏预览，不停止识别。按 **Esc** 返回 TouchDesigner 编辑器；按 **F1** 回到展示窗口。退出作品时关闭 TouchDesigner 即可。

TouchDesigner 已完成安装与许可设置后，作品所需模型、运行时、山水和音乐均从本地加载，可在离线环境运行。作品会自动使用本机 `127.0.0.1:17980` 完成识别通信；同一电脑请只运行一份作品，避免端口及摄像头冲突。

## 常用设置

按 Esc 返回编辑器，选择根目录下的 **`/artofink`** 组件，在自定义 **Art of Ink** 参数页调整：

| 参数 | 用途 |
| --- | --- |
| `Preview` | 显示或隐藏摄像头预览 |
| `Mute` / `Volume` | 静音与音量 |
| `Gain` | 食指推动强度，默认 24 |
| `Palmstrength` | 摊手效果强度倍率，默认 1 |
| `Reset` | 恢复原图，并将摊手循环重置为波浪 |
| `Fullscreen` | 切换全屏与窗口展示 |
| `Restartcamera` | 重启摄像头与识别，保留当前循环顺序 |

建议保持默认识别频率。若只想观看纯净山水，关闭 Preview 即可；无需停止摄像头。其他参数建议先保持默认，调整后在现场验证视觉效果。

再次部署到另一台电脑时，可以在目标电脑重新下载本仓库，也可以复制现有的完整目录。每台电脑都需要自行安装并完成 TouchDesigner 的许可设置；作品目录不包含 TouchDesigner 安装程序或账户凭据。

## 首次部署检查

正式展示前，建议依次确认：

- 能进入山水展示，图像比例正常，右上角摄像头预览默认出现。
- 《山居吟》可以播放，音量与展示现场相适应。
- 移动单食指可推动山水，收起手指后墨色自然消散与恢复。
- 连续三次“摊手 → 收手 → 再摊手”，依次出现波浪、向外螺旋和扩散水波。
- 需要离线展示时，在完成软件许可设置后，断网重开作品，确认摄像头、音乐与交互仍正常。

## 常见问题

- **摄像头没有画面**：关闭其他占用摄像头的软件，检查系统摄像头访问权限，再使用 Restartcamera 或重新打开作品。默认会优先选择实体摄像头；更换电脑时保持 Camera 参数为空，以便重新自动选择。
- **摊手不触发或频繁中断**：保持整只手在画面内，五指自然张开；避免逆光、手指互相遮挡或手掌离镜头过近。
- **没有声音**：检查系统输出设备、系统音量，以及作品的 Mute 与 Volume。
- **画面卡顿**：将展示窗口保持在前台，关闭高负载软件，并确认使用合适的显卡。不同电脑的实际帧率可能不同。
- **从 GitHub 下载后缺少图像、音乐或模型**：使用 Code → Download ZIP 重新下载并完整解压，或重新克隆仓库；确认不是只下载了 `.toe`。保留目录结构，必要时对照 SHA256SUMS.txt 检查文件是否完整。
- **找不到 `.toe` 或看到多个套在一起的文件夹**：进入同时包含 `ArtOfInk_TD.toe`、`assets/`、`src/` 和 `web/` 的目录，以这里作为作品根目录；README 中的路径均相对此目录。
- **识别加载失败**：在组件参数中打开 Debug 查看状态提示，处理后关闭 Debug，回到山水展示。若存在其他作品实例，先退出它们。
